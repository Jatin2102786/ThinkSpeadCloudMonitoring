## 📱 About
ThinkSpead Cloud Monitoring is an Android dashboard application that provides real-time visibility into cloud infrastructure metrics for the ThinkSpead platform. DevOps teams and system administrators can monitor server health, uptime, resource usage, and alerts — all from their Android device, anywhere.

## ✨ Features
- 📊 **Real-Time Dashboard** — Live cloud metrics and KPIs at a glance
- 🖥️ **Server Monitoring** — CPU, memory, disk usage per server
- 📈 **Performance Graphs** — Historical charts for infrastructure trends
- 🔔 **Instant Alerts** — Push notifications for critical threshold breaches
- 🌐 **WebView Integration** — Embedded cloud console access
- 🔐 **Secure Login** — Token-based authentication for administrators
- 🏥 **Health Status** — Traffic-light indicators for service health
- 📋 **Incident Log** — Chronological history of alerts and events

## 🛠️ Tech Stack
- **Language**: Java
- **UI**: Material Design, WebView, RecyclerView
- **Networking**: Retrofit, OkHttp
- **Architecture**: MVVM
- **Other**: Firebase Cloud Messaging for push alerts

## 🚀 Getting Started

### Prerequisites
- Android Studio (Hedgehog or later)
- Android SDK API 21+

### Installation
1. Clone the repository
   ```bash
   git clone https://github.com/Jatin2102786/ThinkSpeadCloudMonitoring.git
   ```
2. Open in Android Studio
3. Sync Gradle and run on device
